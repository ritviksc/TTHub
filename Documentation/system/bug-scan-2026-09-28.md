# Bug check — 28 September 2026

Reviewed assessment validation/editing and reporting job lifecycle, then ran the backend regression suite, frontend tests and production build. This is a targeted review, not a guarantee that every system path is bug-free.

## Reproduced and fixed

- **Late AI responses could succeed after expiry.** A job starting shortly before its deadline could finish late and be saved successfully if no browser polled while it ran. With polling, the same job could instead be marked failed. Worker claims now check the deadline, and result persistence checks expiry again. Expired responses are marked failed without saving the narrative, independently of polling. Applies to both attendance and physical analysis.
- **Assessment completion did not revalidate its date.** A draft could have its date entered before the participant's birth date was known. After a birth-date correction, completion could still accept a test dated before birth. Completion now reuses the existing date validator; failure rolls back the version change and leaves the draft editable.

Both behaviours were reproduced with failing regression tests before changes. No schema changes or new dependencies are required.

## Files

- `backend/reporting/tasks.py`: check expiry when claiming work and storing its result.
- `backend/reporting/test_job_deadline.py`: simulate a provider response finishing after the deadline without browser polling, for both report types.
- `backend/physical_tests/views.py`: validate the stored date at completion using current participant details.
- `backend/physical_tests/tests.py`: cover completion after a birth-date correction, including rollback of status/version.
- `Documentation/system/bug-scan-2026-09-28.md`: findings and verification notes.

## Manual check

Using fictional data, sign in as staff, create a draft assessment for a participant with no birth date, and record results and an earlier assessment date. Correct the participant's birth date to later than that assessment, then try to complete the draft. Completion should return a date error and preserve the draft; correcting the assessment date should allow completion. The AI deadline case is simulated in the automated test to avoid a real provider call or a long wait.

Browser interaction, a live LLM provider and deployment infrastructure were not tested. No commit or push was made as part of this check.
