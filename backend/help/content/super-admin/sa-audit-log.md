## The Administration page

Open **Administration** to find **Users**, **Audit log** and **Documents**. Users manages staff accounts, roles, branch assignments, deactivation and reactivation. Documents opens organisation and branch files.

## Reading the audit log

Select **Audit log**. Super admins see activity from every kapa. Filter by staff email, activity (Staff changes, Branch settings, Reports, Record updates, Sign-ins), kapa, result (Successful, Could not complete, Not permitted) and a date range, then select **Show activity**. The table shows when, who, what happened, the kapa and the result, newest first.

Staff status changes include deactivation and reactivation. The log also records kapa and quarter changes, report requests and edits, sign-ins and changes to records. It is read-only: entries cannot be edited or deleted. It never stores passwords, AI prompts or report text. Questions to the help assistant are not recorded in the audit log.
