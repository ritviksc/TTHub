## The menu

Super admins work nationally and can see every kapa. The menu has:

- **National overview**: a snapshot across every kapa.
- **Kapa**: the branches. Add a kapa, edit it, assign its staff, set its reporting quarters and manage its documents.
- **Kaumātua**: every participant in every kapa.
- **Users**: staff accounts.
- **Reporting**: attendance, physical testing and ACC reports, and past reports.
- **Documents**: organisation files and every kapa's files.
- **Administration**: the audit log.
- **Help**: this page.

After signing in you land on **Users**.

## Reading other roles' help

As a super admin you can read the Branch Manager and Kaimahi help as well as your own, so you can support your staff. Some tasks only those roles can do, for example only kaimahi create sessions and take attendance.
