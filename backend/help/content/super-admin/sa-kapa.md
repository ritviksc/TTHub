## The kapa list

Open **Kapa**. Search by branch name or region. The **No manager** filter shows kapa that nobody manages. The table lists each kapa with its region, branch manager, number of kaimahi and number of participants. The Attendance and Questionnaire columns, and the filters for sessions and questionnaires, are not in use yet.

Select a row to open that kapa.

## Adding a kapa

Select **Add branch**, enter the name (required) and region (optional), then select **Add branch**. Only super admins can add kapa. Names do not have to be unique, so check the list first to avoid a duplicate.
