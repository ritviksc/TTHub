## Viewing sessions

Open **Sessions** to see your kapa's sessions, filtered by **This month**, **This quarter** or **All**. Select a session to see its present and absent counts, attendance rate, and each person's status and absence reason.

Branch managers see sessions read-only. Only kaimahi can create sessions, take attendance, finalise or reopen a register, and delete a session. Some on-screen text mentions attendance mode or Done; those steps are for kaimahi.

## Following up unfinished registers

A session only counts in attendance totals and reports once its register is finalised. The **Overview** page lists sessions waiting to be finalised. Ask the kaimahi who ran the session to open it, check attendance and select **Done**.

If a finalised register is wrong, the kaimahi can reopen it from the session's **Review attendance** button, correct it, and finalise it again.
