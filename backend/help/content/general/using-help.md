## Browsing the documentation

The left half of the Help page lists the documentation you can read, in folders:

- **General**: help for everyone.
- **Kaimahi**, **Branch Manager** and **Super Admin**: help written for each role. You see your own role's folder, and branch managers and super admins also see the folders for the roles they support.

Inside each folder, articles are grouped into sections such as Sessions, Kaumātua and Reporting. Select a folder to open or close it, and select an article to read it. Type in **Search articles** to find articles by title.

While reading, use **← All articles** to go back to the folders, and **Previous** or **Next** to move through the section.

## Asking the help assistant

The right half is the help assistant. Type a question and press Enter (Shift+Enter starts a new line). The answer appears as it is written; select **Stop** to end it early. Under each answer, **Sources** lists the articles it used; select one to open it on the left. Use **Copy** to copy an answer, **Retry** to ask again after a problem, and **New chat** to start over.

The assistant only uses the documentation on this page. If the documentation does not cover your question, it says so instead of guessing.

## What the help assistant cannot do

The help assistant cannot see or change any records. It does not know about specific kaumātua, sessions, documents or reports, but it can tell you where in the app to find them.

You can ask a limited number of questions each hour. If you reach the limit, wait a while and try again.
