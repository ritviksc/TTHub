## Where files are kept

There are three places for files:

- **Organisation** files are seen by all staff. Only a super admin can upload or change them.
- **Kapa (branch)** files are seen by staff at that kapa and by super admins. Staff at that kapa can upload. The branch manager and super admins can create folders, rename, move and delete.
- **Kaumātua (participant)** files are on the participant's profile, in the **Documents** card. Anyone who can see the kaumātua can see and upload them.

## Uploading and organising files

Kaimahi open **Documents** in the main menu. Branch managers and super admins open **Administration → Documents**. The sidebar shows **Organisation** and your kapa. A super admin can switch kapa with **Change ▾**.

Select **Upload** to add one or more files, or drag files onto the list. Select a folder to open it, or select a file to download it. Each row has a **⋯** menu with Rename, Move and Delete. You only see that menu if you are allowed to use it.

A folder can only be deleted once it is empty.

## Allowed files

You can upload PDF, JPG, PNG, DOCX and XLSX files, up to 10 MB each. The app checks that a file's contents match its type, so renaming a file to a different extension will not work.
